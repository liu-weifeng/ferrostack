`lycan/` (own git repo, remote `ssh://git@192.168.2.107:2222/liuwfng/lycan.git`, branch **master**) is the custom Ubuntu 26.04 installer that replaces subiquity for xvirt. As of 2026-06-01 it does unattended **autoinstall** and builds per-role ISOs. Companion to [[xvirt-components-and-xvirtctl]].

## What works (committed `0677b7f`, pushed)
- **Autoinstall**: boot ISO → lycan reads an answer file → installs unattended → reboots into the node. Trigger via kernel cmdline `lycan.auto` (+ baked `/lycan/answers.yaml`) or `lycan.answers=<path|url>`; `lycan.interactive` forces the wizard. Answer schema on `InstallConfig.from_answers` (lycan/config.py): role(standalone|management|compute) / hostname / network(auto|dhcp|manual) / disk.target(auto=largest non-removable) / users.root_password / center_host(compute) / db / reboot.
- **Build**: `scripts/build-iso.sh <ubuntu-26.04.iso> --role <role> [--answers f] [--out iso] [--bundle dir]`. Bakes answers/<role>.yaml → ISO `/lycan/answers.yaml`, injects lycan into the live **installer** squashfs layer (no chroot-apt), masks subiquity, adds `mkfs.fat`, sets grub to auto-boot.
- **Per-role answer files**: `answers/{standalone,management,compute}.yaml` (default root pw `xvirt`).
- First-boot config it writes: `/etc/xvirt/role.conf` (ROLE+CENTER_HOST+DB_*) + `/etc/xvirt/default-bridge.conf` (BRIDGE_NAME/UPLINK_DEV/UPLINK_MAC/…) → consumed by `xvirt-init.service` (build-deb-xvirt/assets/xvirt-init).

## Ubuntu 26.04 layered-casper GOTCHAS (the hard-won fixes — re-read before touching install.py)
1. **Layered squashfs**: 26.04 casper = base `ubuntu-server-minimal.squashfs` (1.2G) + layer `ubuntu-server-minimal.ubuntu-server.squashfs` (155M) + `.installer` layer (148M, has subiquity+sshd+tools). Codename = **resolute** (Resolute Raccoon). The installable rootfs = minimal+server (NOT installer). Plain `unsquashfs` per-layer CORRUPTS (OverlayFS whiteouts) → must **overlay-mount the layers + cp the merged tree** (`_target_layer_chain` + overlay in `_extract_base_system`).
2. **GPT+BIOS needs a 1MiB ef02 BIOS-boot partition** or `grub-install i386-pc` fails "no BIOS Boot Partition; will not proceed with blocklists". Layout = p1 ef02 / p2 EFI / p3 swap / p4 root.
3. **Minimal target lacks openssh-server** (subiquity apt-installs it) → lycan apt-installs it. Needs: remove baked `file:/cdrom` apt source (else `apt-get update` exits non-zero → install skipped), real `/etc/resolv.conf` for chroot apt (live stub 127.0.0.53 fails in chroot), and `_wait_for_network` (lycan.service waits network-online).
4. **`systemctl enable` fails in a chroot** ("System not booted with systemd") → enable units offline via direct wants-symlink (`_enable_unit`).
5. **casper hijacks reboot** ("remove installation medium, press ENTER") → unattended reboot must be FORCED (`reboot -f` / sysrq) to bypass it.
6. **cloud-init** is in the server image → disable it on xvirt nodes (`/etc/cloud/cloud-init.disabled`), else first-boot churn locks root / overrides netplan.
7. Custom QEMU on this host lacks `efi-virtio.rom` → run nested VMs with `-device virtio-net-pci,...,romfile=`.
